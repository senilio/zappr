# Security Policy

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository
[private vulnerability reporting form](https://github.com/senilio/zappr/security/advisories/new)
instead. Do not include vulnerability details in public issues or discussions.

Reports are acknowledged within seven days. Include affected versions, impact,
and steps to reproduce when possible.

## Maintainer Setup

When making the repository public, enable private vulnerability reporting under
**Settings → Advanced Security**, then verify that the reporting form is
available to other GitHub users. Private vulnerability reporting is available
only for public repositories.
